How to use this list: Find each primary opinion on Google Scholar (scholar.google.com) - search the case name and filter to “case law.” Read the opinion first without any guide. Then write a one-page brief using the 8-part structure in the case guide. Then read a summary on Casebriefs.com or Quimbee to check your understanding. Do not start with the summary. The struggle of reading the raw opinion is the skill you are building.
